# 六个案例，应该怎样说清楚

黄金是真实品种，以下价格和交易情节全部虚构。这里是维护者按案例整理的简明说明，不是实时建议，也不是产品答复的逐字转录。原问题见[六个案例](gold-cases.md)，原始问题与新版独立回答见[复测原始记录](../evals/results/0.3.2-independent.json)。

## 1. 4320 开仓，4280 止损，现在想提损

先说清：还不能只凭这两个价格确定新止损。需要知道现在的虚构价格、想调到哪里，以及为什么调整。

如果是多单，把止损上移后仍低于开仓价，触发时仍可能亏损。移动止损也不等于已经成交。回答应帮助核对调整依据，不直接批准一个新价位。

## 2. 4000 买，4200 卖，没接回，后来到 4700

没有接回，不等于 4200 卖错了。后来涨到 4700，是事后才知道的结果。

值得复盘的是：当时为什么认为涨够了，准备在什么条件下接回。如果当时已有安排，就按原安排核对；你没说出来，不代表当时没有。少参与后面的上涨，也不能直接记成账户亏损。

## 3. 原文说确认后观察，却理解成 4385 可以买

这段理解省略了条件。原文先要求一小时收盘站上 4400，再要求随后回踩不破 4380，才观察向 4500 发展的可能；跌破 4350 则判断失效。

“观察可能”不能改成“现在可以买”。只有一个 4385，也看不出前面的条件是否已按顺序发生。

## 4. 当前 4385，等 4400 确认后重新核对

这份草案可以用三句话说明：

- 如果一小时收盘高于 4400，且此前没有先跌破 4350，就重新核对开仓计划。
- 如果确认前先跌破 4350，就取消这次等待。
- 如果两个条件都没出现，就继续观察。

确认后仍只是重新核对，不是自动开仓。仓位和入场后止损还没定；4350 的“跌破”按什么口径算，也需要说清。当前 4385 不足以核验此前是否触发过条件。

## 5. 把“接不回来怎么办”做成候选提醒

提醒可以写成：**卖出后如果还想低位接回，就同时想一想不给回补机会时怎么办。**

临场问自己：如果接不回来，我准备怎么处理？我能接受这次卖出的结果吗？

这张卡目前只是候选提醒，没有成为个人纪律。没有选回补价或比例，就保留未选；不因为做了一张卡，就要求以后必须留底仓或必须追回。

## 6. 4400 减半，没等到 4200，4700 后退出

这单有可以肯定的地方：4400 减半后，剩余仓位仍参与了后面的上涨。没在 4200 接回，不自动否定这次分批退出。

还需要核对的是：两次“势头变弱”分别看到了什么，是否依据当时的安排。最终清仓也不自动表示 4200 的回补计划已经取消。可以肯定材料支持的动作，不替你补出“从未追价”“完全按计划”等没有说明的优点。

## 为什么需要优化

旧版能找到问题，但有时话太多、结论太满。新版同时调整判断和表达：先回答眼前的问题，用已给事实解释，再只问影响结论的关键缺项。

| 旧答复里出现的说法 | 更准确、容易理解的表达 |
| --- | --- |
| “你没有回补条件” | “你还没说当时按什么条件接回。” |
| “4385 低于 4400，所以条件未成立” | “只看现在 4385，还不知道此前有没有收盘确认。” |
| “清仓后，4200 回补计划已被替代” | “清仓已经发生，但是否取消回补，你还没说明。” |
| 开头列模块、文件、编号，再展开所有字段 | 先说这次怎么看；来源和必要条件随句交代。 |

简短不等于省掉依据。来源、条件顺序、未知项和规则是否已采用，仍要保留。
