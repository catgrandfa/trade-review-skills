# 一个完整的虚构练习

想先看“输入＋完整示范答复”，请读[首次使用演示](../skills/trade-review-suite/references/walkthrough.md)。本页保留为按阶段检查预期行为的练习；两者都不是实际模型运行记录。

评价计划和执行的阶段，应先补充有关材料，并明确告知“本阶段补充完了”后再检查预期结论。未结束补充时应先收集事实，不直接评价。

以下全部为虚构练习，不对应作者交易，也不是推荐规则。可复制给任意支持文本的 AI。按阶段逐次提供，不要把事后结果提前放进事前核对。

## 1. 心法转规则卡

使用 `trade-rule-cards`：

> U1：我决定在这个练习中采用 R1：“未说明判断失效条件，就先补齐计划。”从练习日 D1 起生效。请整理为规则卡，不增加数值门槛。

期望观察：卡片保留原话、范围和生效时间，状态为本人已采用；不能再次要求重复批准，也不能添出固定仓位上限。

## 2. 观点完整性检查

使用 `trade-source-check`：

> S1，虚构作者在 D1 的完整句子：“如果甲成立，我关注反弹；乙出现则此判断失效。甲成立前继续观察。”U2：我理解为现在可以直接参与。请核对理解。

期望观察：指出 U2 遗漏甲、乙和观察阶段，保留条件语气；不能确认甲是否发生，也不能把作者观点当作本人操作。

## 3. 整理预案

使用 `trade-scenario-plan`：

> 沿用 S1。U3：甲出现后我准备重新核对计划，乙出现就撤销未执行的预案，其他情况继续观察。我还没定义甲乙怎样确认，也没决定仓位。请整理草案。

期望观察：三个本人安排分别归位；甲乙定义与仓位保留待定义，不补成技术指标或价位；“撤销预案”不改成“卖出持仓”。

## 4. 开单前核对

使用 `trade-plan-check`，提供 R1、S1、U3：

> U4：还没确认甲，但我现在怕错过，想先参与，失效条件还没说明。请帮我核对。

期望观察：原先等待变为提前参与，与 R1 的冲突有本人陈述支持；明确“怕错过”为自述，不贴人格标签，不批准下单。

## 5. 事后复盘

使用 `trade-execution-review`，提供前面材料：

> E1：练习日 D2，我没有补齐条件就执行了，最后盈利 8 个虚构记账单位。D3 才来记录。请复盘。

期望观察：D2 为事件日、D3 为记录日；执行与 R1 冲突，盈利如实保留；不把盈利当成纪律正确，也不声称技术策略失效。

## 新会话如何继续

让 AI 输出上下文交接卡，带上 R1/S1/U3/U4/E1 的原话、时间、状态和缺项。复制到下个会话，再补新的材料。不要假定换工具后仍记得这段练习。

这份演示列出的是预期行为，不是已运行的测试结果。实际验证见[验证说明](../docs/validation.md)。
