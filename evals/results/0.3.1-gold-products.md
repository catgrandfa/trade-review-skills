# 黄金虚构案例：WorkBuddy 与 ChatGPT 产品试用

日期：2026-09-14。使用已从 GitHub 安装的一体版 `trade-review-suite` 0.3.1，来源提交 `d67a718f8f4136f02ecc65c27a63033189a34384`；安装路径与 ZIP 来源证据见[产品安装记录](../../docs/product-trials-0.3.1.md)。本次没有重新安装、修改运行规则或让产品读取预期答案。

黄金是真实品种；六案的价格、交易情节、观点原文全部虚构。没有将真实账户、私人记录或实时黄金行情带入试验。六案覆盖五个模块，其中执行复盘两案；这是通过一体版调用模块的测试，不是五个独立包的安装测试。

## 输入与隔离

原始问题见 [gold-cases.json](../gold-cases.json)，可复制版本见[案例页](../../examples/gold-cases.md)。G01、G02、G06 保留所指定的口语问法；G03–G05 是同类虚构练习。每次发送的文本由以下前缀加对应 `input` 组成：

> 以下是技能试用：黄金是实际品种，但下述价格和交易情节全部虚构，不代表我的真实持仓，也没有提供实时行情。请使用已安装的 trade-review-suite，按普通用户咨询完成答复，开头简要列出实际加载的模块。问题：

没有向被测产品提供下文的评估意见。ChatGPT 六案各从已安装技能详情点击“在聊天中试用”，保留原生技能引用，分别在新的工作对话运行。模型选择均显示 GPT-5.6 Sol / 轻度。

WorkBuddy 在桌面日常任务运行六案，逐案核对输入。G04 首次被发到 G01 的已有任务中；发现后另开空白新任务，以完全相同的输入补跑，主表采用补跑结果。首次结果另列，不隐藏这次会话隔离偏差。其余五案各在新任务运行。没有清除账号记忆或禁用用户原有技能，因此这里的独立只指对话历史，不等同于无持久状态的实验环境。

WorkBuddy 的模型来自每条完成答复的实际标签；自动快速模式没有固定为同一个模型。两产品用时标签含义不同，不拿该表比较性能。

以下是实际界面答复的关键原句与维护者复核，不是完整逐字转录。只摘录本次虚构案例，未复制账号标识、其他对话或私人路径。加载报告是产品答复的自述；G01 在 WorkBuddy 另直接看到技能调用与共同约定、计划模块、作者经验库的文件读取记录。未将每案的文件读取全过程都导出审计。

## G01：4320 开仓、4280 止损，想提损

**WorkBuddy：**报告读取计划核对及 TE02、TE11。指出“‘现在的行情’没有任何数据进来，以及提损的新依据没有说明”，追问当前虚构价格、拟提价位及依据，没有补造新止损位或判违反个人纪律。保留 4280 原计划版本的建议也有助于后续复盘。

但解释中写“浮亏时上移止损 = 提前兑现亏损；浮盈时上移 = 锁定利润”。这过于简化：上移止损不等于已经成交；即使持仓浮盈，上移后的止损仍可能低于成本。交易方向也未先确认。核心缺项核对有用，这段动作含义不记为准确。

**ChatGPT：**报告读取计划核对及 TE02、TE11。“如果这是做多单”，才计算 `4320−4280=40`；指出当前价格、方向、提损条件和目标止损位缺失。“这也不代表原止损4280本身合理，只能确认它是你报告的原计划。”本案保留了假定与未知，没有给出无依据的新价位。

## G02：4200 卖出后没有接回，后来涨到 4700

**WorkBuddy：**报告读取执行复盘、模板、示例与作者经验库。正确指出“「没接回来」本身也不等于操作失误”，区分判断、执行与结果；仓位、是否全部卖出和实际金额收益保留未知，并追问卖出比例及事前回补条件。

**有缺陷：**先断言“‘接回来’只有意向，没有条件——没有回补价位、没有触发情形、没有时间窗”，随后又问事前有没有定条件。输入只是不提供这些细节，不能断言当时不存在。它还称“我认为判断失效了”和“我涨得难受了”在本次叙述中混在一起，但输入没有这两句动机自述。末尾额外询问称呼和身份，与本案交付无关。

**ChatGPT：**报告读取执行复盘及 TE07、TE08。正确指出后来上涨不能倒推 4200 止盈必然错误，区分卖出和再次入场两项决定；强调踏空不等于账户实际亏损 500 点，候选方法未设为已采用纪律。

**有缺陷：**把“没有为……直接继续上涨准备方案”称为确定问题，并称“真正能确定的问题是……没有明确”。原输入没有提供事前方案，不能把缺失材料变成不存在的事实。答复把 200 点价差称为已经实现的利润，未明确交易方向、数量与费用假定；也倾向按全部卖出、失去后续持仓来叙述，实际卖出比例未知。

## G03：原文有确认条件，却理解成 4385 可以买

**WorkBuddy：**只报告观点检查及共同约定、对照模板。保留 4400 收盘确认、随后回踩不破 4380、4350 失效和“可能”的强度，指出原文没有直接支持买入。没有自动扩展出个人交易预案。

**有缺陷：**表中写“前提未成立即行动，且4385低于门坎”，后文又说触发状态未知。单个 4385 不能排除之前已经收盘站上 4400、随后回踩的路径；“可以买”的理解也不等于实际行动已经发生。应评为材料不支持该理解，而不是确认条件未成立或确认已经行动。

**ChatGPT：**只报告观点检查、共同约定和模板，逐项还原条件、顺序、失效与观点强度。明确“无法仅凭价格判断前两个条件已经依次完成”，也不把“观察可能”升级为买入。本案核心来源与状态检查符合输入。

## G04：4385 观察，等待 4400 收盘确认

**WorkBuddy 独立补跑：**保留“确认后重新核对”而非自动开仓；正确说明取消等待不是平仓，仓位、入场后止损未定义。询问 4350 的跌破口径，末尾将当前触发状态保留未知。

**有缺陷：**预案表中把转移条件写成“触及4350或站上4400即转入对应行”。这把原来的“跌破”改成“触及”，也遗漏了 4400 的一小时收盘要求，与正文对歧义的提醒互相矛盾。附加的“没有时间上限……预案无法结案”也偏强；使用者没有采用强制截止期限的规则。

**首次非隔离运行：**同在 G01 任务内，最终模型为 GLM-5.3-Flash / 1m13s。写“4385，介于4350与4400之间，两条条件均未触发”，凭单点价格判定了有先后关系的历史条件；该回答不替代独立补跑，也不算第七个不同案例。

**ChatGPT：**保留四个分支，明确只有一小时收盘高于 4400 才重新核对，4350 是取消等待的条件，不擅填仓位或止损；主动询问“跌破”的口径。

**仍有状态推断问题：**写“当前对应的是‘条件未成立’：4385低于4400”。可以将“我想等”理解为用户自述仍在等待，但应注明这个解读；单凭 4385 无法核验此前是否发生过收盘确认或先跌破 4350，不能把数字比较当成历史条件验证。

## G05：把回补落空的经验记成候选提醒

**WorkBuddy：**只报告规则卡模块及模板、示例、TE07。保留“状态 = 候选提醒，未采用”、数字未选与不得追溯判违规；引用本人原话并给出临场核对问题。界面显示生成了规则卡 Markdown 文件；本次只核对可见回答和产物名称，没有逐字比较下载文件。

**措辞与范围问题：**“缺一半的动作就会在临场被感受接管”把可能风险说成必然心理过程。用户明确未选固定回补价和比例，回答扩展为观察时间窗、触发信号也“你说没选”；这些额外项应写未提供。末尾又追问既往执行，超出这次完成候选卡片所需。

**ChatGPT：**候选卡保留未采用、未生效、参数未定，明确不强制留底仓，也不禁止按既定条件全部退出。这些边界有用。

**范围与证据问题：**额外运行执行复盘，而使用者只要求将已说明的经验做卡；新增复盘又断言“没有定义回调条件”。输入明确的是没有考虑不回调分支，并非没有任何回调条件。候选状态保持正确，但不记为无缺陷。

## G06：4400 减半，未在 4200 接回，4700 后全部退出

**WorkBuddy：**报告执行复盘及 TE07、TE08，另用 TE05、TE04 作边界提示。将两次“势头变弱”的自述与是否使用同一标准分开核对，不把“我觉得不错”直接等同于符合规则；能看见剩余仓位参与后续上涨的作用。百分比计算注明只是价格算术，不等于账户收益。

**有实质缺陷：**写“4200那条回补计划后来事实上已经不可能触发，被你自己在4700的清仓动作替代了”。清仓不自动证明未来回补不可能，也不证明用户已撤销或替代该计划；其生效、失效与替代状态仍需证据。另将“没接回”推成“没有在更高位置追着买回去”、将未说明的不回调分支称为没写，仍有材料缺项被确定化的问题。

**ChatGPT：**能指出“4400没有一次性清仓，而是保留了1/2仓位，后续上涨仍然参与到了”，并将判断依据、执行、结果分开；未要求必须接回或否定全部退出，也把提炼的提醒标为候选。

**有缺陷：**称“没有为了‘必须接回来’而追着修改回补价”，输入只说没有接回来，没有提供所有计划修改过程。它也直接断言没有准备不回调方案。两次“势头变弱”的标准和最终实际成交价并未给全，正面评价仍应限定为按自述可见的分批退出，而不是完整执行质量已经证明。

## 这轮能说明什么

一体版能在这两款实际产品中处理这些口语化问题，五个模块均得到调用。可见的帮助包括指出提损缺项、还原观点限制、组织等待与取消分支、保留候选规则状态，以及看到分批退出和回补落空是不同的问题。

回答可靠性尚不足以记作十二案全部通过。最重复的问题是把“未提供”写成“当时没有”；另有条件口径被改写、触发状态被单点价格推断，以及回补计划被擅自判为已失效或被替代。以上保留原句，不用最后方向大致正确抵消这些缺陷。

本轮未做无技能对照、统计重复试验、单独五包安装或交易收益验证。新对话不排除账号记忆和其他产品技能影响。这里保存的是 0.3.1 原样运行结果；仓库新增六案输入及生成示例，并不意味着已修复上述问题，也不改变 GitHub 已发布 v0.3.1 的资产。没有以新规则或预期答案重新喂给产品，再把第二次答复冒充首轮表现。
