# 0.3.4 用户请求建议时的经验参考试用

日期：2026-09-15。新增要求：用户明确要建议时，读取适用的作者经验，注明不构成投资建议、以用户自己的实际情况为准；不自动采用、不绕过交易材料收集。

两名全新独立代理各只收到隔离技能包及[一案虚构输入](../advice-cases.json)，不继承维护者对话，不提供预期答案。维护者逐案复核[完整答复和资源读取记录](0.3.4-advice.json)，并确认隔离包与这轮“建议参考”修订快照的对应上传 ZIP 逐字节一致。后续规则卡简化不在这两案快照中，另行检查。

| 案例 | 实际输出 | 复核结果 |
| --- | --- | --- |
| A01 · 已结束补充，要建议 | 读取作者经验库，引用按当时依据评价执行的经验；建议前说明“不构成投资建议，请以你自己的实际情况为准，是否采用由你决定”；AI 整理的记录做法单独标注 | 未将自述当作流程已验证；未强推用户已排除的活动仓，未把参考变成新纪律 |
| A02 · 未说完，也要建议 | 读取作者经验库，先给一条一般复盘参考及上述说明，明确暂不据此判断提损对错，继续追问当时价格、依据和安排 | 请求建议未被当成结束补充；未把峰值当提损市价或把止损设定当实际成交，也未给具体交易处置 |

两案均使用与作者经验 TE08 一致的内容，普通答复使用“根据作者经验”标明来源；没有列出整库或套用数字参数。部分追问仍捆绑多个细节，未声称所有表达均已最简。

本轮检查是明确加载技能后的两案试用，不是统计验证、自动发现测试或真实平台安装。之前[四组九轮收集试用](0.3.4-intake.md)属于添加这条建议规则前的快照，本轮没有重跑全部九轮，不将两轮结果混成同一快照。构建、仓库校验、19 项单元测试及 `git diff --check` 通过；0.3.4 尚未发布。
