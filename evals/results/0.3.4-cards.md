# 0.3.4 日常规则卡试用

日期：2026-09-15。检查默认成品是否简短、易读，以及多轮修改是否会让卡片越堆越长。仅使用[虚构输入](../card-cases.json)。

首轮两名独立代理各只收到隔离技能包与本组输入，不继承维护者对话，不提供预期答案。K01 的后续消息逐轮交付；K02 一轮完成。随后根据实际输出收紧重复说明，再用第三名全新独立代理重跑 K02，不提供首轮输出。[原始记录](0.3.4-cards.json)保留所有输入、答复、读取清单、包摘要及快照范围。

| 案例 | 实际结果 | 复核 |
| --- | --- | --- |
| K01 首轮 | 直接给提醒、场景、两个问题及状态/来源短注，200 字符 | 没展开完整模板，没把三个已撤回的说法写回规则；末尾仍有一行未选参数说明 |
| K01 更新 | 按用户改写重做一张卡，仅保留两个指定问题，133 字符 | 没继续追加问题或旧版本内容，候选状态保留；未自动生成档案 |
| K02 首轮 | 来源、候选状态和非投资建议说明都在，但又附一段练习方法，381 字符 | 内容边界保留，表达仍偏长，因此进一步要求将建议融入卡片，不额外追加练习方案或重复背景 |
| K02 最终复测 | 一个标题、使用场景、两个问题、必要边界及来源状态，293 字符 | 保留作者经验 TE08 及参考说明，没有额外练习计划或重复“一句提醒”；仍长于最简单的本人原话卡 |

字符数按原样输出计算，包含 Markdown 标记，不等于汉字数或实测屏幕高度。最终卡片保留了用户要求的参考说明和必要来源，未为凑字数删除这些信息。

最终 K02 的隔离包与当时构建的一体版 ZIP 逐字节一致；后续又增加制卡前确认歧义及固定模板，本报告全部轮次现为历史快照，不能代表最新包复测。K01 和首轮 K02 对应更早的微调前快照。此前材料收集和建议参考试用也保留为各自快照，没有全量重跑。没有用户可读性访谈、统计重复或实际产品显示/保存测试，不能保证所有模型和屏幕都恰好一屏。
