# 0.3.2 独立行为复测

日期：2026-09-14。修订依据是[0.3.1 的六案产品表现](0.3.1-gold-products.md)。采用短句、具体动作、先结论后依据的表达方式，同时收紧缺项、条件顺序、计划状态和模块范围；不引入运行时外部技能依赖。

六个独立代理各只获得一个虚构案例和隔离副本中的完整技能，不继承维护者对话、不提供预期答案。G01–G05 分别使用五个独立技能，G06 使用一体版。每个代理单独输出用户答复及读取记录；完整结果在 [0.3.2-independent.json](0.3.2-independent.json)。这不是 WorkBuddy 或 ChatGPT 产品运行结果。

维护者逐案复核：

| 案例 | 实际回答中的关键表现 | 复核结论 |
| --- | --- | --- |
| G01 | “移动止损本身不代表已经成交或锁定利润”；明确做多假定，未补新止损 | 修正了动作与成交混淆，追问位置与依据；仍可进一步压缩参数说明 |
| G02 | “回补要等什么条件，你还没展开”；已有安排则还原，新增想法标为事后新增 | 未将未提供说成当时不存在；没有把踏空算成账户亏损 |
| G03 | 保留两个确认步骤、失效条件与可能性；单个 4385 不能判断历史过程 | 未把理解偏差改写为已成交或条件确定未触发 |
| G04 | 保留一小时收盘、严格高于、确认前先跌破；当前分支未知 | 未把触及改成跌破，也未根据单个现价确认历史状态 |
| G05 | “候选提醒，尚未采用为纪律”；AI 问题与本人原话分开，价格与比例未选择 | 直接完成小卡，未附加整笔执行复盘或规定底仓 |
| G06 | 肯定减半后仍参与后续上涨；计划取消状态未知，不虚构从未改价 | 未将清仓写成回补计划自动失效，肯定范围受证据限制 |

六案均未复现本轮重点检查的旧问题。普通答复已不以模块与路径开头，也未逐项打印完整模板；部分回答仍有可压缩的补充说明，不能据此声称所有模型都稳定简洁。

完整来源编号与已采用规则范围另使用既有 S03 衔接案例复核，以检查简化表达是否丢失版本和来源。第七个全新代理的实际回答保留了 R1、E1、U2，按 R1 判断 D2 偏离，区分 D2 发生与 D3 补记，R2 从 D4 生效且不追溯；没有把 AI 核对问题扩大为已采用规则，也没有擅自宣称 R2 替代 R1。结果已另行记入原始记录。

没有无技能对照、统计重复或收益验证。六案同本次改进所用案例，因此是针对已知问题的回归，不证明未知场景的泛化能力。使用的运行文件与仓库拟发布文件逐字节核对一致。

## 产品复测后的第二次修订

上方记录及原始 JSON 对应首轮修订，之后真实产品仍出现缺项变断言、成交价推定和过度评价，见[产品记录](0.3.2-products.md)。增加约定开头的具体措辞对照和模块短答要求后，使用另外六个全新隔离代理重新运行 G01–G06；五个独立版各一案，一体版运行 G06。代理只收到输入和技能资源，不知道预期答案，也没有读取前轮答复。包内正常示例可能同时包含其他案例输入；不声称隐藏了技能自带示例。

最终原样答复和读取记录见 [0.3.2-final-independent.json](0.3.2-final-independent.json)。维护者复核结果：G01 保留多单假定与未成交；G02 保留卖出比例和回补条件未知，三段完成；G03 保留 S1 的顺序及历史触发未知；G04 不用价位区间替代条件，也不凭 4385 判定当前分支；G05 直接交付候选卡并区分 AI 提问；G06 有限肯定分批操作，没有补造成交价、未追价或情绪原因，三段完成。

六案均未复现本轮针对的错误。最终运行文件与隔离副本逐字节一致，ZIP 哈希记在该 JSON。S03 是前一轮修订上的检查，未在第二次修订后重跑；不能把两个快照混成同一次验证。两轮都只是已知案例回归，不证明各产品或各模型稳定遵守。
