# 5. 把教训留成候选提醒

以下人物、品种、价格、日期和交易均为虚构。示范答复为作者编写，不是实际模型测试结果，也不是行情建议。本段自带所需上下文，可独立试用。

## 输入

> 练习品种甲。D2 我没有等原计划的一小时收盘确认就买了，后来净赚 2 个练习记账单位。D3 复盘后，我写下 U2：“别因为这次赚了，就省掉原本要等的确认。”只把这句话做成候选提醒卡，先不采用，不补次数或比例。

## 示范答复

**提醒：别因为这次赚了，就省掉原本要等的确认。**

- 什么时候看：准备跳过原计划的确认条件，尤其想用上次盈利作为理由时。
- 临场问题（AI 整理，候选）：这次条件出现了吗？若准备修订计划，新依据是什么？
- 状态与来源：候选，尚未采用；原话来自你在 D3 的总结 U2。
- 边界：这条提醒不否定有新依据的正常修订，也不证明原来的确认条件必然有效。次数与比例按你的要求不补。
