# 个人规则卡

## 日常版（默认只交付这一部分）

先确认会改变卡片含义的推测，再按以下四项成卡。没有歧义就直接写；本人不愿确认时去掉争议部分。下面是结构提示，不把括号、空字段或制作说明原样输出。简单提醒通常约 100–200 字；不要为字数删掉关键条件、采用范围或来源。

### 规则 ID · 简短标题 · 版本

已有 ID 与版本原样沿用；新卡依当前规则清单分配稳定 ID，并从 v1 开始。后续重复展示不改正文，修订同一规则保留 ID、增加内容版本。

**一句提醒：**沿用原意，用平常说话的方式写；标题已说完整就省略这一行。

**什么时候用：**一个具体场景。

**问自己：**

- 一个能直接回答的问题。
- 另一个必要问题；没有就不凑。

**状态与来源：**候选 / 本人已采用；本人自述 / 根据作者经验 / AI 提议，据实写明。已采用时保留已知生效范围；AI 整理的问题注明，不把整理当成本人认可。

以上为默认成品，ID 和版本只放标题，不附案例价位表、完整交易经过或待填字段清单。必要边界另用一句话说明，未确认推测不进入规则正文。用户要求建议时，把建议融入提醒或问题，保留共同约定的参考说明，不另加一段讲解或练习计划。
