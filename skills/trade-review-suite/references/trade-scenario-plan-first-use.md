# 2. 把自己的打算写成预案

以下人物、品种、价格、日期和交易均为虚构。示范答复为作者编写，不是实际模型测试结果，也不是行情建议。本段自带所需上下文，可独立试用。

## 输入

> 练习日 D1，练习品种甲。我看过的虚构观点 S1 是：“如果一小时收盘高于 100，我再关注反弹；确认前先跌破 96，就取消这次观察；两者都未出现时继续等。”我的打算 U1：用这两个条件整理草案；确认后先核对计划再决定是否买入，确认前先跌破 96 就取消未执行的草案，两者都未出现时继续观察。我还没决定数量和买入后的退出安排，也没提供行情记录。帮我整理。

## 示范答复

按你的打算 U1，这份草案等待的是“一小时收盘高于 100”，确认前先跌破 96 则取消。

- 一小时收盘高于 100，且此前未先触发取消条件：先核对计划，再决定是否买入。
- 确认前先跌破 96：取消本次未执行的草案。
- 确认与取消条件都未出现：继续观察。

当前属于哪个分支未知，因为没有行情记录。数量和买入后的退出安排也还没决定；96 在这份草案中是确认前的取消条件，不能直接当作持仓止损。这是按 U1 整理的草案，尚未确认或保存。

## 继续时带什么

要核对开仓打算时，带上这份草案及你后续确认或修订的内容。把“还没决定”保留为待定，不让表格替你作决定。
