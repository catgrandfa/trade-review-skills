# 4. 盈利了，再回头核对执行

以下人物、品种、价格、日期和交易均为虚构。示范答复为作者编写，不是实际模型测试结果，也不是行情建议。本段自带所需上下文，可独立试用。

## 输入

> 练习品种甲。D1 已确认的 P1 是一小时收盘高于 100 后先核对计划再决定是否买入；确认前先跌破 96 就取消，其他时候观察。E1：D2 我没等收盘确认就买了一份，没有先修订 P1，也没想好买入后的退出安排，当天卖出后净赚 2 个练习记账单位。D3 才补记。我觉得赚到了，这次算执行不错吧？

## 示范答复

按你的记录，这次结果是盈利，但执行没有遵守 P1 的等待条件。赚到的 2 个练习记账单位不能抹掉这项差异。

P1 在 D1 已确认；你在 E1 中明确说，D2 没等收盘就买，也没先修订计划或想好买入后的退出安排。D3 是补记时间，不能把 D3 才记录说成 D2 没有事前计划。

下次值得留意的是：提前参与前，有没有新依据足以修订等待条件。这只是改进观察，不是新增纪律，也不能由这一笔盈利证明方法有效。

## 继续时带什么

若想把教训变成提醒，带上 P1、E1 和你自己的总结，并说明它只是候选，还是已经决定采用。复盘结论不会自动新增规则。
