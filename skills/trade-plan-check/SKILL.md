# 开单前计划核对

提损只是在讨论修改退出安排。即使新止损高于开仓价，也不能写成已经锁定价格收益；应说“如果按该价成交，会有怎样的价差”，并保留成交与成本未知。多空方向未明确时，用“如果这是多单”说明假定。

帮助使用者检查“我现在准备做的事，是否符合自己的计划和依据”。先读取[共同复核约定](references/review-contract.md)，以其来源、时间和规则边界处理输入。本技能可以独立使用。

## 处理方式

1. 从自然语言提取本次打算；识别它是新交易、原计划分批、持仓管理还是计划修订。已发生的操作不能写成尚待执行。
2. 找到使用者提供的原计划、当时适用的已采用规则及本轮新信息。没有历史材料就说明只能核对当前陈述。
3. 核对依据与适用场景、触发、失效、仓位及风险安排、持仓管理、退出。涉及加仓时关注增加后的总暴露与原预算；信息不足就保留缺项。
4. 将本次打算与原计划逐项比较。改变本身不等于违规；核对新的依据、修订时间，以及相关规则是否允许修订。
5. 分开给出完整性、计划一致性、规则对照和证据局限。有明确冲突时同时引用计划/规则与本人陈述。

## 关键判断

涉及相关场景时，读取[作者经验参考库](references/author-experience.md)的 TE01–TE06、TE09–TE10；加减仓后续安排可参考 TE07。先区分“经验参考”与本人已采用规则，数字 TN 参数单独核对选择状态。

- “等回调”缺少具体定义时，只能判定条件不够明确，不自行补成某条均线、百分比或价位。
- 原计划要求某条件出现，而当前是否出现未知时，计划一致性也待核对。不能把“未提供触发证据”写成“条件没有触发”，也不能只凭“现在想参与”确定与原计划冲突。只有本人明确准备绕过条件，或材料明确表明条件未满足却准备行动时，才指出该项冲突。
- 同样，条件是否满足未知时，不要把“现在参与”定性为已经修改或必然需要修改原计划；它可能仍在执行原计划。先核对条件的定义和当前状态，再判断是沿用、可能变更还是明确变更，不预设本人放弃了原条件。
- “我已经设了止损”可以记录为自述，金额风险仍取决于仓位、产品和单位。不要把止损存在直接视为风险可承受。
- 提损核对先区分交易方向、当前价格、拟调位置与调整依据。移动止损不等于已经成交；多单浮盈时把止损上移，也可能仍低于成本。价差只有在明确方向与计算假定后才计算，不能写成账户收益或已锁定利润。原止损与新止损是否合理分别待核对，不因已设置而认可位置。
- 只因更换研究标的、出现亏损或使用杠杆，不能认定情绪交易。结合本人自述和前后记录给出有限判断。
- 信息完整且未见冲突时，如实报告；不制造新的规则门槛，也不批准或代替下单。

## 交付

先用一句话说目前最值得核对的地方，再给必要的证据、缺项和下一步。建议使用[核对卡](templates/plan-check.md)，短问题可以简化。需要给新会话使用时附[上下文交接卡](references/context-template.md)。
