# 上下文交接卡

按本次已知信息填写，不要求使用者补齐整张表。没有提供的内容填“未提供”，有冲突的内容并列保留。

- 本次任务：
- 复核阶段：收集材料 / 用户已结束补充；结束补充的本人原话、时间与本次范围。新一轮关键补充另记，不沿用旧的结束状态。
- 事件发生时间 / 记录时间：
- 标的与产品类型 / 周期 / 方向 / 价格单位：
- 本人已采用规则：规则 ID、原文、版本、生效时间、适用范围、采用依据。
- 候选规则与修订：稳定规则 ID、完整正文、内容版本、采用状态；若是修订，另保留仍生效的旧版本及其正文。转采用不另分 ID，交接不重编已有编号。
- 作者经验参考：条目 ID 与库版本；仅参考 / 本人已采用；选定的数字参数及口径，未选择则保留未选择。
- 外部观点与个人判断：来源 ID、来源日期、原话或定位、条件与限制。
- 原计划：计划 ID、版本、依据、触发、失效、仓位、风险、管理与退出；草案 / 本人已确认 / 已撤销。
- 实际操作：来源 ID、发生时间、本人明确报告的动作与结果。
- 本轮新增说明：区分当时已有但现在补记的内容与事后新解释。
- 待核对项：缺项、版本冲突、仅为自述尚未独立验证的事项。
- 本次复核结论：收集期间留待总结；用户结束补充后记录材料支持的发现及仍未知的部分，分别引用证据。被新事实推翻的判断标为撤回，不带入候选卡。
- 后续修订：草案或本人确认状态；不回写为过去事实。

下一次使用时把这张卡连同有关原文一起提供。摘要用于导航，有疑义时回到原文。
